# Spin & Win Android App

This project is configured to build an Android APK automatically with GitHub Actions.

## Build on GitHub
1. Upload the project files to a GitHub repository.
2. Open the **Actions** tab.
3. Select **Build Spin & Win APK**.
4. Click **Run workflow** (or push to `main`).
5. When the build finishes, open the workflow run and download the **SpinWin-debug-apk** artifact.

The APK is a debug build for testing. AdMob has not been added yet.
